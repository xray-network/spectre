    </div>
    <p>SPECTRE is a Markdown-only protocol that keeps work with coding agents clear and reviewable. For example, when you ask an agent to plan a <code>/health</code> endpoint, SPECTRE records the scope and required checks in <code>0002-IMPL-INSTR.md</code>. When you then ask the agent to implement the change, it updates the source and tests, runs the required checks, and produces <code>0002-IMPL-RESULT.md</code> with the files changed and actual test results. The root <code>SPECTRE.md</code> ledger tracks the change as it moves from <code>PLANNED</code> to <code>REVIEW</code> and, after your decision, <code>ACCEPTED</code> or <code>REJECTED</code>. These Markdown files stay beside the code, giving reviewers a durable account of what was requested, what the agent changed, how it was validated, and who approved it.</p>
  </section>
